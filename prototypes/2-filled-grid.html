Prototype 2Filled square mosaic — the live site's look, rebuilt: measure the text height once per layout, derive the row count, map each highlight to a row by its position, fill the leftover cells with empty placeholders. One ResizeObserver, batched read→write, no reflow storm, no Safari reload, no browser sniffing.
Styling (colours, type scale, spacing, thumbnail + empty-cell treatment, hover states) is taken from index.html, so only the layout algorithm differs. Responsive: the image column is a percentage (60/40, 80/20 under 600px) so cells shrink with the window, and the columns never stack. Column count, gap and padding are read from the CSS itself — no breakpoint duplicated in JS. Hover text ⇄ image; click to enlarge.
